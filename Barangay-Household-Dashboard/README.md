
# Barangay Household Profile Analysis and Social Assistance Planning Dashboard

## Project Description
This project analyzes barangay household information to help support
community planning and social assistance prioritization.

## Objectives
- Analyze household socioeconomic characteristics.
- Identify household patterns using clustering.
- Support planning of social assistance programs.
- Provide interactive data visualization.

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly

## How to Run

Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Dataset
The dataset is located in the data folder.

Use anonymized or authorized household data only.
